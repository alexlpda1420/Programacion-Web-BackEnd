## Descripción

Este repositorio contiene las actividades, prácticas y proyectos realizados durante el curso de **Programación Web Back End** de **Potrero Digital**.

El objetivo del curso es profundizar en la lógica de programación del lado del servidor, integrando el **Front End** con el **Back End** mediante el uso de tecnologías como **HTML**, **CSS**, **PHP** y herramientas de desarrollo web.

## Proyecto destacado: Login

La tarea de login tiene como objetivo crear un sistema básico que permita validar un usuario y una contraseña.

## Cómo ejecutar los proyectos

Para ejecutar los proyectos que utilicen PHP, se recomienda usar **XAMPP**.

### Pasos

1. Descargar o clonar este repositorio.
2. Copiar la carpeta del proyecto dentro de la carpeta `htdocs` de XAMPP.
3. Iniciar el servidor **Apache** desde el panel de XAMPP.
4. Abrir el navegador e ingresar a:

```bash
http://localhost/Programacion-Web-BackEnd/
```

Para acceder directamente a la tarea de login:

```bash
http://localhost/Programacion-Web-BackEnd/tarea-login/login.html
```
