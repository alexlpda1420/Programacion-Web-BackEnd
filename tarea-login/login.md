# Crear un Login que valide Usuario y Contraseña

## Objetivo

Crear un sistema de login que valide **Usuario** y **Contraseña**.

Además, se debe relacionar el **Front-End** con el **Back-End**.

## Estructura del proyecto

La estructura debe comprender los siguientes archivos:

- `login.html`  
  Formulario donde el usuario carga los datos.

- `login.php`  
  Recupera los datos del formulario, los guarda en variables y valida el login.

## Opcional

- `error.html`  
  Página que informa el error y devuelve al usuario a `login.html`.

## Herramientas permitidas

Para la realización de la tarea pueden valerse de todas las herramientas vistas en clase, por ejemplo:

- Plantillas
- Templates
- IA
- Otras herramientas vistas en clase

## Entrega

Para la entrega deben realizar una de las siguientes opciones:

1. Comprimir la carpeta del proyecto en formato `.zip` y entregarla.
2. Subir el proyecto a un repositorio de GitHub y compartir la dirección del repositorio.
